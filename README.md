# LunarCrack-Linux
A simple script that generates a Minecraft account entry for Lunar Client on Linux.  It prompts for a username and a UUID, then creates the required JSON account file  inside the Lunar Client configuration directory. This allows the client to load  the provided account information without any manual editing.


# Install Lunar Client
- Use Flatpak to download the client
```
flatpak install flathub com.lunarclient.LunarClient
```

# SetUp

Download files:
```
git clone https://github.com/FlaxonWeb/LunarCrack-Linux.git
```

Open Folder:
```
cd LunarCrack-Linux
```

Granting permissions to the file:
```
chmod +x account.sh
```

Run file:
```
./account.sh
```

# How to Get UUID

- open namemc.com
- select skin and Click on it 
- click skin name
- copy UUID
